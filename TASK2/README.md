# 📊 Task 2 - Customer Segmentation Analysis

## Project Overview

This project focuses on Customer Segmentation using K-Means Clustering. The objective is to group customers with similar purchasing behavior and identify valuable customer segments for targeted marketing strategies.

## Objectives

* Perform data cleaning and preprocessing.
* Analyze customer spending patterns.
* Create new features using feature engineering.
* Apply K-Means Clustering to identify customer groups.
* Visualize customer segments.
* Generate business recommendations based on cluster insights.

## Dataset Information

The dataset contains customer demographic information, purchasing behavior, income details, campaign responses, and product spending records.

## Tools & Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Outlier Detection & Removal
4. Exploratory Data Analysis (EDA)
5. Feature Engineering
6. Data Standardization
7. Principal Component Analysis (PCA)
8. K-Means Clustering
9. Cluster Evaluation (Elbow Method & Silhouette Score)
10. Business Insights & Recommendations

## Key Findings

* Four customer segments were identified using K-Means Clustering.
* Income and total spending were major factors influencing customer groups.
* High-income customers showed significantly higher product spending.
* Relationship status also influenced customer purchasing behavior.
* Different clusters require different marketing approaches.
