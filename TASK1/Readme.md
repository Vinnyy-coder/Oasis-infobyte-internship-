# 📊 Task 1 - EDA on Retail Sales Data

## Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on retail sales data and uncover meaningful business insights.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Data Cleaning
- Missing Value Analysis
- Sales Trend Analysis
- Customer Behaviour Analysis
- Data Visualization
- Business Insight Generation

## Key Insights

- Identified sales trends and patterns.
- Analysed customer purchasing behaviour.
- Generated visualizations to support business decision-making.

## Outcome

The project successfully extracted meaningful insights from retail sales data and demonstrated the practical application of exploratory data analysis techniques.
