# Task 4 : Sentiment Analysis

## Overview

This project performs Sentiment Analysis on Twitter data using Natural Language Processing (NLP) and Machine Learning techniques. The objective is to classify tweets into Positive, Neutral, and Negative sentiments.

## Features

* Data Cleaning and Preprocessing
* Natural Language Processing (NLP)
* TF-IDF Feature Engineering
* Multiple Machine Learning Models
* Sentiment Prediction
* Data Visualization
* Word Cloud Analysis
* Confusion Matrix Evaluation

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* NLTK
* WordCloud
* Scikit-Learn

## Dataset

Dataset: Twitter_Data.csv

Sentiment Labels:

* Positive (1)
* Neutral (0)
* Negative (-1)

## Project Workflow

1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Text Preprocessing
5. Exploratory Data Analysis
6. Word Cloud Generation
7. TF-IDF Feature Engineering
8. Model Training
9. Model Evaluation
10. Sentiment Prediction

## Machine Learning Models

* Naive Bayes
* Logistic Regression
* Support Vector Machine (SVM)

## Evaluation Metrics

* Accuracy Score
* Classification Report
* Confusion Matrix

## Results

The final sentiment classification model achieved approximately 86% accuracy and successfully classified tweets into Positive, Neutral, and Negative categories.
